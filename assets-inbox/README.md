# assets-inbox（画像の受け取り口）

Geminiで作った画像（PNG）を、加工する前の状態でここに置きます。
ファイル名と作り方は docs/ART_GUIDE.md を参照してください。

- ここに置いた画像を、Claude Codeが加工してゲームに入れます（背景の透過、表情ごとの切り分け、縮小、WebPへの変換）。
- ゲームはこのフォルダを直接読み込みません。
- **元の画像（PNG）は git に入れません**（`.gitignore` で除外）。公開リポジトリの履歴に残り続けて重くなるのを避けるためです。作り直しや再加工に必要なので、元の画像はご自身で保管してください（Google ドライブなど）。
