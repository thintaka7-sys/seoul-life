# assets-inbox（画像の受け取り口）

Geminiで作った画像を、加工する前の状態でここに置きます。PNG（`.png`）と JPEG（`.jpg`・`.jpeg`・`.jpe`）のどれでもかまいません（Gemini は今後 JPEG で書き出すため）。
ファイル名と作り方は docs/ART_GUIDE.md を参照してください。

- ここに置いた画像を、Claude Codeが加工してゲームに入れます（背景の透過、表情ごとの切り分け、縮小、WebPへの変換）。
- ゲームはこのフォルダを直接読み込みません。
- **元の画像（PNG・JPEG）は git に入れません**（`.gitignore` で除外）。公開リポジトリの履歴に残り続けて重くなるのを避けるためです。作り直しや再加工に必要なので、元の画像はご自身で保管してください（Google ドライブなど）。

## 加工のしかた（開発者向け）

```
npm run assets
```

- どの画像を何として使うかは `scripts/assets/assets.config.json` に書きます。
- できた WebP は `public/assets/`、画像の一覧は `src/data/assets/manifest.json` に書き出されます。この2つをコミットします。
- 画像を差し替えるときは、同じファイル名で置いてから `npm run assets` を実行します（画像の一覧の `?v=…` が変わり、ブラウザに古い画像が残りません）。
- ファイル名は拡張子を除いた名前で探します。同じ名前で拡張子の違う画像が複数あるとき（`bg_home.png` と `bg_home.jpe` など）は、**新しいほう（更新日時の遅いほう）**を使います。設定（`assets.config.json`）のファイル名は、拡張子を書いても書かなくてもかまいません。
- ここにない画像は飛ばします（ゲームでは仮の絵を出します）。
- 透過の結果を目で確かめるときは `npm run assets -- --preview <フォルダ>` で、目立つ色の上に重ねた確認用の画像も書き出せます。

**表情を並べた画像（`char_*_sheet`）の注意**
- 人物どうしの間に、背景だけの縦のすき間が必要です（すき間で切り分けます）。
- 背景の緑は、縁とつながっていない部分（腕と体の間など）も、背景の色にとても近ければ透明にします。
- 立ち絵には緑を使わない決まりなので、人物全体から緑みを取ります。わざと緑で描いた部分（이수진 のかんざしの葉）は、設定の `keepGreen` に元の画像の位置（画素）を書いて残しています。作り直して位置が変わったら、ここも直します。
