# 教材JSONの書き方

「서울에서 살기」の教材（単語・文法・会話）を JSON ファイルで作るための説明です。
教材を作るチャットに、このファイルをそのまま渡して使えます。

- 教材を作る流れと確認の手順は GAME_SPEC.md 11-4 を参照してください。
- この説明と見本は、プログラムの検証ルールと一致しているかを自動テストで確かめています（`src/data/contentFormatDoc.test.ts`）。

---

## 1. ファイルの置き場所

| 種類 | フォルダ | ファイル名の例 |
|---|---|---|
| 単語 | `src/data/vocabulary/` | `ch01.json`、`ch03_cafe.json` |
| 文法 | `src/data/grammar/` | `ch02.json` |
| 会話 | `src/data/scenarios/` | `ch03_cafe.json` |

- フォルダに `.json` ファイルを置くと、自動で読み込まれます。ファイル名は自由です。章ごとに分けるのがおすすめです（`ch01.json`、`ch02.json` …）。
- 1つのファイルには、1種類のデータの**配列**（`[ … ]`）を入れます。単語と文法を同じファイルに混ぜないでください。
- 同じフォルダにある `sample.json` は、プログラムの動作確認用の仮データです。本番の教材が届いたら削除します。

---

## 2. JSONを書くときの決まり

- 文字コードは UTF-8 にします。
- 文字列は `"ダブルクォート"` で囲みます。シングルクォートは使えません。
- 最後の項目の後ろにカンマを付けません。JSON にはコメントも書けません。メモは `notes` 項目に書いてください。
- `true` / `false` と数字は、引用符で囲みません（`"level": 1`。`"level": "1"` は誤り）。
- 表にない項目名を書くとエラーになります。綴りの間違い（例：`pronounciation`）を見つけるためです。
- ハングルは普通に入力した文字で書きます。字母（ㅋ ㅓ ㅍ ㅣ）を並べた形にはしません。プログラムはUnicode正規化（NFC）された文字かどうかを確かめます。

---

## 3. ID の決まり

- **一度ゲームに入れたIDは、後から変えたり使い回したりしません。** セーブデータと学習記録がIDで教材を参照しているためです。不要になった教材は削除してよいですが、そのIDは二度と使いません。
- IDは、単語・文法・会話のすべてを通して重複できません。別のファイルにあっても重複はエラーになります。
- 番号は3桁以上にします（`001`、`002` … `999`、`1000`）。
- **900番台（`vocab_901` など）は、プログラムの仮データ用に予約しています。** 本番の教材では使わないでください。

| 種類 | 形式 | 例 |
|---|---|---|
| 単語 | `vocab_番号` | `vocab_001` |
| 文法 | `grammar_番号` | `grammar_001` |
| 会話 | `英小文字の名前_番号`（施設ID＋番号を推奨） | `cafe_001`、`convenience_store_001` |

---

## 4. 共通の項目

すべての単語・文法・会話に付けます。

| 項目 | 必須 | 型 | 意味 |
|---|---|---|---|
| `id` | 必須 | 文字列 | 一意のID（3章） |
| `reviewed` | 必須 | true / false | 韓国語を確認済みか。作ったときは `false` にし、別のAIや韓国語母語話者の確認が済んだら `true` にする |
| `notes` | 任意 | 文字列 | 確認者のメモ（確認した人・日付・気になった点など） |

---

## 5. 単語

| 項目 | 必須 | 型 | 意味 |
|---|---|---|---|
| `korean` | 必須 | 文字列 | 韓国語（見出し語）。正解判定では、これが模範解答になる |
| `alternatives` | 任意 | 文字列の配列 | 正解として認める別表記（例：`짜장면` に対する `자장면`）。1個以上入れる。`korean` と同じものは入れない |
| `pronunciation` | 必須 | 文字列 | 発音のカタカナ表記（補助として表示する） |
| `japanese` | 必須 | 文字列 | 日本語訳 |
| `partOfSpeech` | 必須 | キー | 品詞（7-1のキー一覧から選ぶ） |
| `category` | 必須 | キー | カテゴリ（7-2のキー一覧から選ぶ） |
| `level` | 必須 | 整数（1以上） | 難しさ。1がいちばんやさしい |
| `example` | 任意 | 文字列 | 例文（韓国語） |
| `exampleJapanese` | 任意 | 文字列 | 例文の日本語訳。`example` と必ずセットで書く |

**`alternatives` について**
- 空白の違い（分かち書き）と、句読点（. , ? !）、全角・半角の違いは、判定のときにプログラムが吸収します。そのため、こうした違いだけの別表記を `alternatives` に入れる必要はありません。
- 意味は同じでも別の単語（類義語）は、原則として入れません。入れる場合は、`notes` に理由を書いてください。

---

## 6. 文法

| 項目 | 必須 | 型 | 意味 |
|---|---|---|---|
| `title` | 必須 | 文字列 | 文法の名前（例：`이에요 / 예요`） |
| `level` | 必須 | 整数（1以上） | 難しさ |
| `explanation` | 必須 | 文字列 | 日本語での説明。初心者に分かる簡単な言葉で書く |
| `examples` | 必須 | 配列（1個以上） | 例文。各要素は下の表のとおり |

`examples` の各要素：

| 項目 | 必須 | 型 | 意味 |
|---|---|---|---|
| `korean` | 必須 | 文字列 | 例文（韓国語） |
| `japanese` | 必須 | 文字列 | 日本語訳 |
| `alternatives` | 任意 | 文字列の配列 | 例文を答えさせる問題で、正解として認める別の言い方 |

GAME_SPEC 4-3 にある接続ルール・穴埋め問題・並べ替え問題の項目は、Phase 1〜2 で追加します。項目を追加するときは、この説明も更新します。

---

## 7. キーの一覧

### 7-1. 品詞（`partOfSpeech`）

| キー | 意味 | 例 |
|---|---|---|
| `noun` | 名詞 | 커피、학생 |
| `pronoun` | 代名詞 | 저、이거 |
| `numeral` | 数詞 | 하나、일 |
| `verb` | 動詞 | 가다、먹다 |
| `adjective` | 形容詞 | 좋다、맛있다 |
| `adverb` | 副詞 | 아주、같이 |
| `particle` | 助詞 | 은/는、을/를 |
| `determiner` | 冠形詞（連体詞） | 이、그、저 |
| `interjection` | 感嘆詞・返事 | 네、아니요 |
| `greeting` | あいさつ・お礼・お詫びの決まった表現 | 안녕하세요、감사합니다 |
| `expression` | その他の決まった言い回し | 잠깐만요 |

### 7-2. 単語のカテゴリ（`category`）

| キー | 意味 |
|---|---|
| `greeting` | 挨拶 |
| `people` | 人 |
| `food` | 食べ物 |
| `drink` | 飲み物 |
| `number` | 数字 |
| `time` | 時間（曜日・日付を含む） |
| `place` | 場所（方向を含む） |
| `shopping` | 買い物 |
| `daily_life` | 日常生活 |
| `emotion` | 感情 |
| `verb` | 動詞 |
| `adjective` | 形容詞 |

### 7-3. 施設ID（会話の `location`）

| キー | 施設 |
|---|---|
| `home` | 自宅 |
| `cafe` | カフェ |
| `convenience_store` | コンビニ |
| `bookstore` | 本屋 |
| `park` | 公園 |
| `station` | 駅 |

### 7-4. キャラクターID・話者ID（会話の `character` と `speaker`）

| キー | 人物 | `character` に使える | `speaker` に使える |
|---|---|---|---|
| `friend` | キャラクターA：近所の友人 | ○ | ○ |
| `cafe_staff` | キャラクターB：カフェの店員 | ○ | ○ |
| `neighbor` | キャラクターC：近所の住人 | ○ | ○ |
| `player` | 主人公（プレイヤー） | × | ○ |

- キャラクターの名前・口調は Phase 3 で決めます。IDは役割を表す名前のまま変えません。
- 施設・キャラクターを追加したいときは、教材を作る前に開発者に伝えてください。プログラム側のデータ（`src/data/locations/`、`src/data/characters/`）への追加が必要です。

## 8. 会話

| 項目 | 必須 | 型 | 意味 |
|---|---|---|---|
| `chapter` | 必須 | 整数（1〜10） | 何章の会話か（GAME_SPEC 5章） |
| `location` | 必須 | キー | 会話する施設（7-3） |
| `character` | 必須 | キー | 会話の相手（7-4。`player` は使えない） |
| `lines` | 必須 | 配列（1個以上） | プレイヤーが答える前の台詞 |
| `choices` | 必須 | 配列（1個以上） | 選んで答えるときの選択肢。`"correct": true` を1つ以上入れる |
| `freeAnswer` | 任意 | オブジェクト | 書いて（話して）答えるときのお題と正解 |

`lines` の各要素：

| 項目 | 必須 | 型 | 意味 |
|---|---|---|---|
| `speaker` | 必須 | キー | 話す人（7-4） |
| `korean` | 必須 | 文字列 | 台詞（韓国語） |
| `japanese` | 必須 | 文字列 | 日本語訳 |

`choices` の各要素：

| 項目 | 必須 | 型 | 意味 |
|---|---|---|---|
| `korean` | 必須 | 文字列 | 選択肢（韓国語）。同じ会話の中で重複させない |
| `japanese` | 必須 | 文字列 | 日本語訳 |
| `correct` | 必須 | true / false | 正解か。正解は複数あってもよい |

`freeAnswer`：

| 項目 | 必須 | 型 | 意味 |
|---|---|---|---|
| `prompt` | 必須 | 文字列 | 日本語のお題（例：「コーヒーをください」） |
| `answers` | 必須 | 文字列の配列（1個以上） | 正解。**先頭が模範解答**で、2つ目以降が別解。自然な言い方が複数ある場合は、すべて入れる |

- 丁寧語とタメ口は、キャラクターとの関係に合わせて使い分けます（GAME_SPEC 2-3）。
- 1つの会話データは「台詞 → プレイヤーの返事」の1往復です。何往復も続く会話の書き方は Phase 1 で決めて、この説明に追加します。

## 9. 見本

下の3つは、そのまま検証を通る見本です。中身は GAME_SPEC.md 11章の例をもとにしています。
本番の教材では、ID を900番台以外にしてください（見本では `001` を使っています）。

### 単語（`src/data/vocabulary/ch01.json` など）

<!-- sample: vocabulary -->
```json
[
  {
    "id": "vocab_001",
    "korean": "안녕하세요",
    "pronunciation": "アンニョンハセヨ",
    "japanese": "こんにちは",
    "partOfSpeech": "greeting",
    "category": "greeting",
    "level": 1,
    "example": "안녕하세요. 저는 유키예요.",
    "exampleJapanese": "こんにちは。私はユキです。",
    "reviewed": false
  },
  {
    "id": "vocab_002",
    "korean": "짜장면",
    "alternatives": ["자장면"],
    "pronunciation": "チャジャンミョン",
    "japanese": "ジャージャー麺",
    "partOfSpeech": "noun",
    "category": "food",
    "level": 2,
    "reviewed": false,
    "notes": "자장면 も標準語として認められているため別表記に入れた"
  }
]
```

### 文法（`src/data/grammar/ch02.json` など）

<!-- sample: grammar -->
```json
[
  {
    "id": "grammar_001",
    "title": "이에요 / 예요",
    "level": 1,
    "explanation": "名詞の後につけて「～です」と表す表現です。",
    "examples": [
      { "korean": "저는 학생이에요.", "japanese": "私は学生です。" }
    ],
    "reviewed": false
  }
]
```

### 会話（`src/data/scenarios/ch03_cafe.json` など）

<!-- sample: conversations -->
```json
[
  {
    "id": "cafe_001",
    "chapter": 3,
    "location": "cafe",
    "character": "cafe_staff",
    "lines": [
      { "speaker": "cafe_staff", "korean": "어서 오세요!", "japanese": "いらっしゃいませ！" },
      { "speaker": "cafe_staff", "korean": "뭐 드릴까요?", "japanese": "何になさいますか？" }
    ],
    "choices": [
      { "korean": "커피 주세요.", "japanese": "コーヒーをください。", "correct": true },
      { "korean": "집에 가요.", "japanese": "家に帰ります。", "correct": false },
      { "korean": "안녕하세요.", "japanese": "こんにちは。", "correct": false }
    ],
    "freeAnswer": {
      "prompt": "コーヒーをください",
      "answers": ["커피 주세요.", "커피 한 잔 주세요."]
    },
    "reviewed": false
  }
]
```

## 10. 書いたファイルを確かめる

ファイルを置いたら、プロジェクトのフォルダで次を実行します。

```
npm run test
```

- 問題がなければ、すべてのテストが通ります。
- 問題があれば、`data/ の実データ > 検証で問題が1件もない` のテストが失敗し、`ファイル名 / 何番目 / ID / 項目: 理由` の形で一覧が表示されます。
- 問題のあるデータは、ゲームでは読み込まれません（ゲームは止まらず、そのデータだけ除外されます）。開発中は、タイトル画面にも件数が表示されます。
