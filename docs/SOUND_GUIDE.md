# 音素材の手引き（効果音・BGM）

- 作成：2026-11-22（Claude・教材担当）
- 方針は GAME_SPEC 10-4。このファイルは、素材の候補・Gemini での BGM の作り方・使う素材の一覧をまとめたもの。
- 決まったこと（2026-11-22、開発者と相談）：
  - **BGM の6曲は、すべて Gemini（Lyria 3.5）で作ったものを使う**（開発者が聞いて決めた。4章の一覧）。OpenTracks・CC0 の BGM は、曲を足したくなったときの候補として残す。
  - **効果音**は CC0（権利を放棄した素材）を中心にする。
  - **BGM** は、まず Gemini（開発者の Google AI Pro プラン）で試しに作り、OpenTracks（旧 DOVA-SYNDROME）の曲と聞き比べて決める。

## 1. BGM が必要な場面

全部を別の曲にしなくてよい。3〜4曲を使い回せば十分。

| 場面 | 雰囲気 | 優先 |
|---|---|---|
| カフェ | 落ち着いたおしゃれな店。少しジャズ・ボサノバ風 | 最初に試す |
| 自宅 | 穏やかで温かい。新しい部屋でほっとする | 最初に試す |
| タイトル | 明るく、これから始まるわくわく感 | |
| 街のマップ | 軽く歩きたくなる、明るい日常 | |
| 学習画面 | 落ち着いて集中できる。目立たない | |
| おはなし（空港・タクシー） | 少しの緊張と、新しい生活への期待 | |

## 2. Gemini で BGM を作る

### 2-1. 作り方

1. Gemini アプリで「音楽を作成」（ツールの「音楽」）を選ぶ。
2. 下の指示文を、場面ごとにそのまま貼る。
3. 長さは、まず「短い（約1分）」で試す。気に入ったら「フル」で作り直してもよい。
4. 歌が入ってしまったら、「歌なし、インストゥルメンタルだけで作り直して」と頼む。
5. 気に入った曲をダウンロードして、ファイル名を `bgm_場面.mp3`（例：`bgm_cafe.mp3`）にし、プロジェクトの `assets-inbox/audio/` に置く。
6. 作った日・モデル名（画面に出ていれば）・使った指示文を、4章の素材一覧に書く（開発者が Claude に伝え、Claude が書く）。

### 2-2. 守ること

- **歌なし**（インストゥルメンタル）にする。韓国語の学習中に歌詞が聞こえると邪魔になるため。
- **アーティスト名・曲名・作品名を指示に入れない**（「〇〇風」と頼まない）。雰囲気と楽器で伝える。
- **ループ向き**にする。BGM はくり返し流すので、最後にフェードアウトせず、最初と最後の雰囲気をそろえる。つなぎ目の調整は Claude Code がする。
- 規約や使える範囲がよく変わるので、作った日を必ず残す。
- 「フェードアウトしないで」と頼んでも、最後がフェードアウトすることがある（2026-11-22 の2曲とも）。気にしなくてよい。つなぎ目は Claude Code が調整する。

### 2-3. 指示文（場面ごと）

どの指示文にも、最後に共通の一文が入っている。

**カフェ**
```
ゲームのBGMを作ってください。場面は、ソウルのおしゃれで落ち着いた小さなカフェです。
ジャンル：ボサノバ風のやさしいジャズ。テンポはゆったり（90BPMくらい）。
楽器：ナイロン弦のギター、エレクトリックピアノ、ウッドベース、ブラシで叩くドラム。
雰囲気：温かく、くつろげる。会話のじゃまにならない控えめな音量感。
歌なし（インストゥルメンタルのみ）。最後はフェードアウトせず、ループして流しても自然につながるように、最初と最後の雰囲気をそろえてください。
```

**自宅**
```
ゲームのBGMを作ってください。場面は、ソウルに引っ越してきたばかりの主人公の、小さくて明るい部屋です。
ジャンル：穏やかなアコースティック・ポップ。テンポはゆったり（80BPMくらい）。
楽器：やわらかいピアノ、アコースティックギター、少しだけグロッケン。
雰囲気：ほっとする、温かい、新しい生活への小さな期待。
歌なし（インストゥルメンタルのみ）。最後はフェードアウトせず、ループして流しても自然につながるように、最初と最後の雰囲気をそろえてください。
```

**タイトル**
```
ゲームのタイトル画面のBGMを作ってください。韓国・ソウルで新しい生活を始める、アニメ調の明るい学習ゲームです。
ジャンル：明るく軽やかなポップ。テンポは中くらい（100〜110BPM）。
楽器：アコースティックギター、ピアノ、グロッケン、軽い打楽器、手拍子。
雰囲気：わくわく感、晴れた朝、これから始まる冒険。
歌なし（インストゥルメンタルのみ）。最後はフェードアウトせず、ループして流しても自然につながるように、最初と最後の雰囲気をそろえてください。
```

**街のマップ**
```
ゲームのBGMを作ってください。場面は、ソウルの住宅街の地図画面で、行き先を選ぶところです。
ジャンル：軽快で楽しい日常系のポップ。テンポは少し速め（110BPMくらい）。
楽器：ウクレレ、ピアノ、ベース、軽いドラム、口笛のようなシンセ。
雰囲気：散歩したくなる、明るい、少しおどけた感じ。
歌なし（インストゥルメンタルのみ）。最後はフェードアウトせず、ループして流しても自然につながるように、最初と最後の雰囲気をそろえてください。
```

**学習画面**
```
ゲームのBGMを作ってください。場面は、韓国語の文字や単語を勉強する画面です。
ジャンル：落ち着いたローファイ（lo-fi）。テンポはゆっくり（75BPMくらい）。
楽器：やわらかいエレクトリックピアノ、控えめなビート、あたたかいベース。
雰囲気：集中できる、静か、目立たない。読み上げの韓国語の声がはっきり聞こえるよう、音数を少なく。
歌なし（インストゥルメンタルのみ）。最後はフェードアウトせず、ループして流しても自然につながるように、最初と最後の雰囲気をそろえてください。
```

**おはなし（空港・タクシー）**
```
ゲームのBGMを作ってください。場面は、主人公がソウルの空港に着いて、タクシーで新しい家に向かうところです。
ジャンル：映画のような、やさしいインストゥルメンタル。テンポは中くらい（90BPMくらい）。
楽器：ピアノ、弦楽器（ストリングス）、軽い打楽器。
雰囲気：少しの緊張と、新しい生活への期待。だんだん明るくなる。
歌なし（インストゥルメンタルのみ）。最後はフェードアウトせず、ループして流しても自然につながるように、最初と最後の雰囲気をそろえてください。
```

## 3. ほかの候補

### 3-1. 効果音（CC0）

| 使う場面 | 候補 | 入手先 |
|---|---|---|
| ボタン・正解・不正解 | Kenney「Interface Sounds」（100個） | https://kenney.nl/assets/interface-sounds |
| 同上（別の候補） | Kenney「UI Audio」（50個） | https://kenney.nl/assets/ui-audio |
| 経験値・合格・スタンプ | Kenney「Music Jingles」（85個） | https://kenney.nl/assets/music-jingles |
| カフェのドアのベル | pleasing bell sound effect | https://opengameart.org/content/pleasing-bell-sound-effect |

- Kenney はページに試聴がないので、無料でダウンロードして聞く。
- 足りない効果音（カップを置く音、呼び出しベルの振動など）は、出てきたときに CC0 で探す。

### 3-2. BGM（CC0）

| 候補 | 入手先 | メモ |
|---|---|---|
| Two Simple Game Music Loops | https://opengameart.org/node/174263 | メニュー用とゲーム中用の2曲。明るくなつかしい |
| Simple menu/background music loop | https://opengameart.org/node/186484 | メニュー・会話向き |
| Coffee Beans | https://opengameart.org/node/142667 | カフェ向き |
| CC0 - Calm / Relaxing Music（一覧） | https://opengameart.org/node/73274 | Bossa Shop Theme（カフェ）、A New Town（街）、Calm Piano 1（学習）など |

- lofi Compilation（OpenGameArt）は CC0 だが、1曲が既存の曲とほぼ同じとして自動の申し立てを受けたという書き込みがあるので、使わない。

### 3-3. BGM（OpenTracks）

- https://opentracks.com/ で「日常」「ほのぼの」「カフェ」「かわいい」などのタグで探す。
- 使う場合は、ゲームに「利用規約」のページ（音のファイルを取り出してゲーム以外に使うことを禁止する、など）を用意する。曲ごとに作曲者の条件も確かめる。
