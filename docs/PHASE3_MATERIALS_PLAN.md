## 1. 物語の流れ（第1〜3章）

今の「1日目」（お隣さん → カフェ）を、章立てに組み直す。カフェは第3章に移る。

| 章 | 場面の順番 | 新しく作るもの |
|---|---|---|
| 第1章 韓国に到着 | ① 空港に着く（おはなし）→ ② タクシーで家へ（おはなし）→ ③ 先生と初めてのオンライン授業（おはなし。ハングル学習へ案内）→ ④ お隣さんにあいさつ（会話 home_005・006。今のもの）→ ⑤ 先生とふり返り（おはなし）→ ⑥ 章末テスト | おはなし4本、単語の追加（공항・택시 など）、章末テスト |
| 第2章 自己紹介 | ① 家の前で友人 윤하나 と出会う（おはなし）→ ② 自己紹介（会話）→ ③ 簡単な質問に答える（会話）→ ④ 先生とふり返り（おはなし）→ ⑤ 章末テスト | すべて新しく作る：単語・文法・会話・おはなし・コラム・章末テスト |
| 第3章 初めてのカフェ | ① 하나 にカフェをすすめられる（会話またはおはなし）→ ② カフェに入る（会話 cafe_008）→ ③ メニューを読む（読み物）→ ④ 注文する（cafe_009 と、書く・話す専用の「注文」）→ ⑤ 注文を聞き取る（リスニング）→ ⑥ 名物スイーツ 크로플 のおはなし → ⑦ 先生とふり返り → ⑧ 章末テスト | メニューの単語、読み物、注文の教材、おはなし2本、リスニングの追加、章末テスト |

- どの章の最後にも、先生とのふり返り（短いおはなし）を置く（GAME_SPEC 2-3）。
- コラムは今の2本（column_001・002）を使い、第2章に1本足す（韓国の自己紹介の習慣：年齢を聞く理由など）。

## 4. 作る順番（予定）

Claude Code は仕組みを先に作る（GAME_SPEC 12章）。教材もそれに合わせる。

1. Claude Code の区切り1：おはなし・読み物・タップ・先生の表示・図や絵・形が変わる言葉の「教材の形」を決める。
2. 教材担当：第1章の教材（おはなし4本、単語の追加、章末テスト）と、先生の話し方に直した説明（ハングルのレッスン12本・文法3・ドリル4・聞き分けのこつ15組）。友人と先生の名前の確認。背景（空港・タクシーの中・家の前の道）と図の絵（口の形・激音の息・パッチムの舌と唇）の ART_GUIDE の指示文。
3. 教材担当：第2章の教材（全部）。
4. 教材担当：第3章の教材（メニュー・注文・読み物・おはなし・章末テスト）。
5. それぞれ ChatGPT の確認を受けてから、content-inbox に置く。

## 5. 決めたこと（2026-11-22、開発者と相談）

1. 第2章の自己紹介で名前を言う場面は、名前を出さずに地の文（「……（あなたは名前を伝えた）」など）にする。練習するのは出身と職業。名前をハングルで書く練習は、将来のおまけの候補（GAME_SPEC 15章）。
2. 職業の「選択」の選択肢は、회사원（会社員）・학생（学生）・주부（主婦・主夫）・프리랜서（フリーランス）。

## 6. Claude Code の Phase 3 計画（2026-11-23）で決まったこと

- 3回の区切り：①教材の形 → ②物語の仕組み（章の組み直し、おはなし、タップ、先生の枠、BGM）→ ③学習の仕組みと仕上げ（図と絵、形が変わる言葉、読み物、注文、第2・3章、章末テスト）。
- イベントの組み直し：第1章＝event_004（空港・タクシー）→ event_005（先生の初授業。ここで「ハングルは読めますか？」）→ event_001（お隣さん）→ event_006（ふり返り）。第2章＝event_007 → event_008。第3章＝event_009（カフェが開く）→ event_002（入店・メニュー・注文・聞き取り）→ event_010（크로플）→ event_011（ふり返り）。
- 新しい教材の種類：おはなし story_、読み物 reading_、メニュー menu_、注文 order_。台詞の glosses（字が一致しない語句のタップ用）、単語の base・forms、説明の figures。
- 立ち絵のない人物（運転手・空港の係員など）は名札だけ。章末テストは次の章へ進む条件にしない。読み物の問題は復習に入れない。
- 図の絵のファイル名は fig_キー.png。
