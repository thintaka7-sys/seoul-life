# 教材の表記ルール

「서울에서 살기」の教材（韓国語の文・カタカナの読み・正解の決め方）をそろえるための約束です。
JSONの形式は docs/CONTENT_FORMAT.md、作り方と確認の手順は GAME_SPEC.md 11-4 を参照してください。

## 1. カタカナの読み（フリガナ）

カタカナは発音の補助です。ㅓとㅗの違いなど、カタカナでは表せない音があるため、読み上げと一緒に使う前提で書きます。

| 決まり | 例 |
|---|---|
| 韓国語と同じ位置で空白を入れて区切る（単語ごとにフリガナを付けるため）。句読点は入れない | 아메리카노 한 잔 주세요. → アメリカノ ハン ジャン ジュセヨ |
| 実際の発音どおりに書く（連音化・鼻音化・ㅎの弱化などを反映する） | 집에 → チベ、감사합니다 → カムサハムニダ、주문하신 → チュムナシン |
| 文の中で濁る音は、濁った形で書く。単語単独の読みでは濁らせない | 주세요 → チュセヨ（単独）、커피 주세요 → コピ ジュセヨ |
| 数と単位（値段の 원 など）は一息で言うため、空白をまたいで起こる連音化も反映する。区切りの位置は韓国語に合わせる | 오백 원 → オベ グォン、천 원 → チョ ヌォン、만 오천 원 → マ ノチョ ヌォン |
| 濃音（ㄲ・ㄸ・ㅃ・ㅆ・ㅉ）は「ッ」を付けて表す | 빵 → ッパン、맛있어요 → マシッソヨ、드릴까요 → ドゥリルッカヨ |
| ただし、ㄱ・ㄷ・ㅂ の音のパッチム（ク・ッ・プ と書く音）の直後の濃音には「ッ」を付けない。詰まる音がすでに表れているため | 고맙습니다 → コマプスムニダ、옆집에 → ヨプチベ、학생 → ハクセン |
| 激音（ㅋ・ㅌ・ㅍ・ㅊ）は清音で書き、のばす記号（ー）は使わない | 커피 → コピ、케이크 → ケイク |
| ㅢ は位置に関係なく「ウィ」、ㅝ は「ウォ」、뭐 は「ムォ」と書く | 뭐 → ムォ |

## 2. 丁寧さ（話し方）

| 話す人 | 話し方 |
|---|---|
| 近所の住人（neighbor） | 主人公より少し年上。丁寧語（해요体）で、主人公には尊敬語も使う（例：오신 걸 환영해요） |
| カフェの店員（cafe_staff） | 接客の丁寧な言い方（합니다体・해요体。例：여기 있습니다、뭐 드릴까요?） |
| 近所の友人（friend） | 同年代。最初は丁寧語、仲良くなったらタメ口（반말）。切り替える章は Phase 3 で決める |
| 主人公（player）の返事 | 第1〜3章は丁寧語（합니다体・해요体）を基本にする |

## 3. 正解の決め方

- 選ぶ問題（choices）では、正解（correct: true）を1つだけにする。何を言えばよいかを日本語で示し（書く・話すの問題と同じ内容）、その内容に合う返事だけを正解にする。不正解の選択肢は、初心者が間違えやすいものを選ぶ（例：店を出るときの 안녕히 가세요）。話が変わるだけの場面は、問題ではなく「選択」にする（GAME_SPEC 4-4）。
- 書く・話す問題（freeAnswer）では、その場面で自然な言い方をできるだけ正解に含める。先頭は、その章で教えている形にする。
- 句読点・空白・全角半角の違いはプログラムが吸収するので、その違いだけの別解は入れない。

## 4. 確認の記録

- 確認が済んだら reviewed を true にし、notes の末尾に「確認：確認した人（日付）」を書く。
- 確認者の指摘を採用しなかった場合は、その理由を notes に書く。
