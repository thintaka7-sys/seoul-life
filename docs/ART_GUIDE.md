# 絵の作り方（Gemini用）

「서울에서 살기」の立ち絵・背景を、Geminiで作るための手順と指示文です。
絵柄は **日本のアニメ調の立ち絵（腰から上）** です（GAME_SPEC.md 8-1）。

アニメ調は、AIで何枚も描くと顔や服がぶれやすい絵柄です。この手順は、ぶれを防ぐことを第一にしています。

---

## 1. 始める前に

1. **右下のマークを消す設定：** Geminiの設定に「Media watermark（メディアの透かし）」があればオフにします。オフにした後に作った画像にだけ効きます。
2. **キャラクターごとにチャットを分ける：** 1人のキャラクターは、最初から最後まで同じチャットで作ります。別のチャットで作ると、別人になりやすくなります。
3. **緑を使わない：** キャラクターは無地の緑の背景で作り、あとで緑の部分を透明にします。服や髪、小物に緑が入ると一緒に消えてしまうので、キャラクターには緑を使いません。

---

## 2. 共通の絵柄指定

すべての指示文の最初に、この文を付けます。

```
日本のアニメ調の2Dイラスト。きれいな線画、セル塗りにやわらかい影。明るく温かい色合いで、大人も楽しめる落ち着いた雰囲気。文字・ロゴ・透かしは入れない。
```

---

## 3. キャラクター

### 3-1. デザインの考え方

現実の人のような見た目ではなく、ゲームのキャラクターとして、ひと目で覚えられるデザインにします（性格や会話の内容は変えません）。

- **シルエットで見分けられる：** 髪型と髪の色を、キャラクターごとにはっきり変える。
- **テーマカラーを1色決める：** 服や小物に入れる。ゲーム画面の名前の欄などの色にも使う。
- **チャームポイントは2〜3個：** 性格や好きなものとつながる小物にする。
- **作り直しにも強い：** 特徴がはっきりしているほど、AIで描き直したときにずれに気づきやすく、そろえやすい。

### 3-2. 作る順番（1人ごと）

1. **基準の画像を作る（手順A）**：何回か作り直して、いちばん気に入った1枚を決めます。これがそのキャラクターの「正解の顔」になります。
2. **表情を並べた画像を作る（手順B）**：基準の画像と同じチャットで、表情だけを変えた3人分を横に並べた1枚を作ります。1枚の中で作るので、顔や服がそろいやすくなります。
3. **確かめる**：最後のチェックリスト（6章）で確認します。ずれていたら、手順Bをやり直します。

### 3-3. 店員（cafe_staff）

| 項目 | 案（変更できます） |
|---|---|
| 名前 | 한지훈（ハン・ジフン） |
| 年齢・性格 | 20代半ばの男性。落ち着いていて丁寧。実は甘いものに目がない |
| テーマカラー | キャラメル色 |
| チャームポイント | ふわふわのミルクティー色の髪と、頭のてっぺんでぴょんとはねた一房のくせ毛／いつも少し眠たげな、はちみつ色の半目／エプロンの胸元の、ピンク色のマカロン型ピンバッジ（甘いもの好きの印） |
| 服 | 白いシャツ（袖を少しまくる）、キャラメル色のエプロン、片耳に小さな銀のイヤーカフ |

**手順A：基準の画像**

```
（共通の絵柄指定）
ゲームの立ち絵。韓国・ソウルの小さなカフェで働く、20代半ばの男性店員。落ち着いていて丁寧な雰囲気。
髪はふわふわしたミルクティー色（明るいベージュブラウン）のショートヘアで、頭のてっぺんに一房だけぴょんとはねたくせ毛がある。目ははちみつ色で、いつも少し眠たげな半目。
白いシャツの袖を少しまくり、キャラメル色のエプロンをつけている。エプロンの胸元に、ピンク色のマカロン型のピンバッジ。片耳に小さな銀のイヤーカフ。
腰から上を描く。体はほぼ正面を向き、両手は体の前で軽く重ねる。表情は穏やかな微笑み。
服・髪・小物に緑色は使わない。
背景は、影も床もない、無地の明るい緑（#00FF00）一色。縦長の画像（縦3：横2）。
```

**手順B：表情を並べた画像**（手順Aと同じチャットで、気に入った画像を添付して）

```
添付した画像の人物と、同じ顔・髪型・服装・小物・絵柄のまま、同じポーズで表情だけを変えた3人分を、横一列に並べた1枚の画像にしてください。
左から順に、
1. 穏やかな微笑み（通常）
2. 口を開けた明るい笑顔
3. 眉を少し下げた、困ったような微笑み
3人の大きさと高さはそろえ、重ならないように間をあけてください。
くせ毛・ピンバッジ・イヤーカフなどの特徴は、3人とも同じ位置に描いてください。
背景は影も床もない無地の明るい緑（#00FF00）一色のまま。横長の画像（縦9：横16）。
```

## 4. 背景・マップ

背景は人物を描かず、あとから立ち絵を重ねます。チャットは、キャラクターとは別にします（背景用に1つ）。

**自宅（主人公の部屋）**

```
（共通の絵柄指定）
ゲームの背景画像。ソウル市内の小さなワンルームの部屋。引っ越してきたばかりで、段ボール箱がいくつか残っている。ベッド、小さなテーブル、窓から差し込む朝のやわらかい光。
人物は描かない。文字は描かない。縦長の画像（縦16：横9）。
```

**カフェの店内**

```
（共通の絵柄指定）
ゲームの背景画像。ソウルの住宅街にある、小さくて居心地のいいカフェの店内。客が立つ位置から、正面のカウンターを見た構図。木のカウンター、エスプレッソマシン、ケーキとパンが並ぶガラスケース、観葉植物。カウンターの奥の壁に、文字の書かれていない黒板のメニュー。カウンターの後ろには人が立てる空間をあける。
人物は描かない。文字は描かない。縦長の画像（縦16：横9）。
```

**自宅の玄関**（近所の住人が訪ねてくる場面に使います）

```
（共通の絵柄指定）
ゲームの背景画像。ソウルの小さなマンションの部屋の玄関を、部屋の中から見た構図。開いた玄関のドア、靴を脱ぐ一段低いスペース、靴箱、ドアに付いた暗証番号式の電子ロック（ボタンに文字や数字は描かない）。ドアの外は明るい共用廊下。ドアの前に人が立てる空間をあける。
人物は描かない。文字は描かない。縦長の画像（縦16：横9）。
```

**街のマップ**

```
（共通の絵柄指定）
ゲームのマップ画像。ソウルの小さな住宅街を、斜め上から見下ろしたイラスト。次の6か所を画面全体に散らばるように配置し、道でつなぐ：アパート（主人公の家）、カフェ、コンビニ、本屋、木のある公園、地下鉄の駅の入口。
それぞれの建物は形や色で見分けがつくようにする。看板には文字を書かない（無地）。人物は描かない。縦長の画像（縦16：横9）。
```

## 5. 保存と受け渡し

できた画像は、PNGで保存して次の名前を付けます。

| 画像 | ファイル名 |
|---|---|
| 店員の基準の画像 | `char_cafe_staff_base.png` |
| 店員の表情を並べた画像 | `char_cafe_staff_sheet.png` |
| 近所の住人の基準の画像 | `char_neighbor_base.png` |
| 近所の住人の表情を並べた画像 | `char_neighbor_sheet.png` |
| 自宅 | `bg_home.png` |
| 自宅の玄関 | `bg_entrance.png` |
| カフェ | `bg_cafe.png` |
| 街のマップ | `map_town.png` |

- 置き場所は、プロジェクトの `assets-inbox/` フォルダです。背景を透明にする処理、表情ごとの切り分け、縮小、軽い形式（WebP）への変換は、Claude Codeが行います。
- スマホで作った場合は、Claudeとのチャットに画像を送れば、フォルダに置いてもらえます。

## 6. 採用する前のチェックリスト

- [ ] 顔・髪型・服が、基準の画像と同じか（表情を並べた3人の間でもそろっているか）
- [ ] チャームポイント（くせ毛・マカロンのバッジ・イヤーカフ／お団子・かんざし・泣きぼくろ・エプロン）が描かれていて、すべての絵で同じ側にあるか
- [ ] 指や手の形が崩れていないか
- [ ] 文字・ロゴ・マークが入っていないか（看板・名札・メニューも）
- [ ] 背景の緑が均一で、影やグラデーションがないか
- [ ] キャラクターの服・髪・小物に緑が入っていないか
- [ ] 背景とマップに人物が描かれていないか

**よくある失敗と直し方**

| 失敗 | Geminiへの頼み方 |
|---|---|
| 看板や黒板に文字が入った | 「看板（黒板）の文字を消して、無地にしてください。それ以外は変えないでください」 |
| 表情を変えたら服が変わった | 基準の画像を添付し直して、「服装は添付した画像とまったく同じにしてください」と付け加えて作り直す |
| 背景に影が入った | 「人物の足元や後ろの影を消し、背景を無地の緑一色にしてください」 |
