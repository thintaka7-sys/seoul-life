# 絵の作り方（Gemini用）

「서울에서 살기」の立ち絵・背景を、Geminiで作るための手順と指示文です。
絵柄は **日本のアニメ調の立ち絵（腰から上）** です（GAME_SPEC.md 8-1）。

アニメ調は、AIで何枚も描くと顔や服がぶれやすい絵柄です。この手順は、ぶれを防ぐことを第一にしています。

---

## 1. 始める前に

1. **右下のマークを消す設定：** Geminiの設定に「Media watermark（メディアの透かし）」があればオフにします。オフにした後に作った画像にだけ効きます。
2. **キャラクターごとにチャットを分ける：** 1人のキャラクターは、最初から最後まで同じチャットで作ります。別のチャットで作ると、別人になりやすくなります。
3. **緑を使わない：** キャラクターは無地の緑の背景で作り、あとで緑の部分を透明にします。服や髪、小物に緑が入ると一緒に消えてしまうので、キャラクターには緑を使いません。

---

## 2. 共通の絵柄指定

すべての指示文の最初に、この文を付けます。

```
日本のアニメ調の2Dイラスト。きれいな線画、セル塗りにやわらかい影。明るく温かい色合いで、大人も楽しめる落ち着いた雰囲気。文字・ロゴ・透かしは入れない。
```

---

## 3. キャラクター

### 3-1. デザインの考え方

現実の人のような見た目ではなく、ゲームのキャラクターとして、ひと目で覚えられるデザインにします（性格や会話の内容は変えません）。

- **シルエットで見分けられる：** 髪型と髪の色を、キャラクターごとにはっきり変える。
- **テーマカラーを1色決める：** 服や小物に入れる。ゲーム画面の名前の欄などの色にも使う。
- **チャームポイントは2〜3個：** 性格や好きなものとつながる小物にする。
- **作り直しにも強い：** 特徴がはっきりしているほど、AIで描き直したときにずれに気づきやすく、そろえやすい。

### 3-2. 作る順番（1人ごと）

1. **基準の画像を作る（手順A）**：何回か作り直して、いちばん気に入った1枚を決めます。これがそのキャラクターの「正解の顔」になります。2人目からは、すでにいるキャラクターの基準の画像を添付して「絵柄・大きさ・構図をこの画像にそろえて（顔や服はまねしない）」と頼むと、そろいやすくなります。
2. **表情を並べた画像を作る（手順B）**：基準の画像と同じチャットで、表情だけを変えた3人分を横に並べた1枚を作ります。1枚の中で作るので、顔や服がそろいやすくなります。
3. **確かめる**：最後のチェックリスト（6章）で確認します。ずれていたら、手順Bをやり直します。

```

**手順B：表情を並べた画像**（手順Aと同じチャットで、気に入った画像を添付して）

```

1. 穏やかな微笑み（通常）
2. 口を開けた明るい笑顔
3. 眉を少し下げた、困ったような微笑み

```

### 4-2. カフェのメニューの品物

第3章のカフェで、メニューを見て注文する場面（GAME_SPEC 4-4）に使う絵です。品物の絵だけを作り、品名と値段は絵に入れません（ゲームの画面に文字で出します）。

- 6品ずつ2枚に分けて作ります。1枚の中で作ると、絵柄と大きさがそろいやすいためです。
- 背景は、キャラクターと違って緑にしません（抹茶ラテなどが一緒に消えてしまうため）。無地のクリーム色にして、透明にはせず、正方形のカードとしてそのまま使います。マスの切り分けは Claude Code がします。
- 2枚は同じチャットで作ります。2枚目は1枚目を添付して「同じ絵柄・同じマスの大きさで」と頼みます。

**1枚目：飲み物（`menu_cafe_1.png`）**

```
（共通の絵柄指定）
ゲームで使う、カフェのメニューの品物の絵。6つの品物を、横3列・縦2段に並べた1枚の画像にしてください。
1つずつ同じ大きさの正方形のマスに描き、マスどうしの間をあけてください。各マスの背景は無地のクリーム色（#FFF4E0）で、マスの外も同じクリーム色。影はやわらかく小さく。
どの品物も、少し斜め上から見た同じ角度で、マスの中央に同じくらいの大きさで描く。かわいらしく、おいしそうに。
上の段の左から：
1. ホットのアメリカーノ（白い陶器のカップとソーサー、黒いコーヒー）
2. カフェラテ（白い陶器のカップとソーサー、ハートのラテアート）
3. バニララテ（白い陶器のカップとソーサー、明るいベージュのラテ、横に小さなバニラビーンズのさや）
下の段の左から：
4. 抹茶ラテ（白い陶器のカップとソーサー、淡い緑のラテ、葉っぱのラテアート）
5. いちごラテ（背の高い透明なグラス、下にいちごのピンクのソース、上に白い牛乳、氷）
6. ゆず茶（透明なガラスのマグ、明るい黄色のお茶、薄く切ったゆずの皮が浮いている）
人物・手・テーブル・文字・ロゴ・値札は描かない。カップやグラスにも文字や模様を入れない。横長の画像（縦2：横3）。
```

```

## 6. 採用する前のチェックリスト

- [ ] 顔・髪型・服が、基準の画像と同じか（表情を並べた3人の間でもそろっているか）
- [ ] チャームポイント（くせ毛・マカロンのバッジ・イヤーカフ／お団子・かんざし・泣きぼくろ・エプロン／インナーカラー・丸めがね・ショルダーバッグ・星の飾り／白髪まじりの髪・黒ぶちめがね・胸ポケットのペン）が描かれていて、すべての絵で同じ側にあるか
- [ ] ほかのキャラクターと、絵柄（線の太さ・塗り）と、大きさ・構図（頭の大きさ、太ももの上あたりまで入る引いた構図）がそろっているか。並べて比べる
- [ ] 基準の画像（通常の表情）で、目が開いているか
- [ ] 指や手の形が崩れていないか
- [ ] 文字・ロゴ・マークが入っていないか（看板・名札・メニューも）
- [ ] 背景の緑が均一で、影やグラデーションがないか
- [ ] キャラクターの服・髪・小物に緑が入っていないか
- [ ] 背景とマップに人物が描かれていないか

**よくある失敗と直し方**

| 失敗 | Geminiへの頼み方 |
|---|---|
| 看板や黒板に文字が入った | 「看板（黒板）の文字を消して、無地にしてください。それ以外は変えないでください」 |
| 表情を変えたら服が変わった | 基準の画像を添付し直して、「服装は添付した画像とまったく同じにしてください」と付け加えて作り直す |
| 背景に影が入った | 「人物の足元や後ろの影を消し、背景を無地の緑一色にしてください」 |
| ほかのキャラクターより大きく写った・絵柄が違う | 今の画像と、ほかのキャラクターの基準の画像（例：`char_cafe_staff_base.png`）を一緒に添付して、「1枚目の人物を、2枚目の画像と絵柄・線の太さ・大きさ・画面の中の位置をそろえて描き直してください。1枚目の顔・髪型・服・小物は変えず、2枚目の人物の顔や服はまねしないでください」と頼む |
