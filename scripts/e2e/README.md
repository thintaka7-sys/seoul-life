# ブラウザでの確認スクリプト（scripts/e2e）

ヘッドレスの Edge（なければ Chrome）を動かして、実際の画面を操作して確かめるスクリプトです。
追加のパッケージは使いません（Node 24 の組み込みの `fetch` と `WebSocket` で DevTools プロトコルを使います）。
単体テスト（`npm run test`）では分からない、画面の動き・見た目・コンソールのエラーを確かめるために使います。

## 使い方

```
npm run build
npm run preview          # 別のターミナルで。http://localhost:4173/seoul-life/ で開く
node scripts/e2e/chapters.mjs http://localhost:4173/seoul-life/
```

- URL を変えれば、開発サーバー（`npm run dev` の http://localhost:5173/seoul-life/）や公開URL（https://thintaka7-sys.github.io/seoul-life/）でも同じように確かめられます。
- 結果は `OK / NG` の一覧と件数で表示します。NG があるか、コンソールのエラー・警告や通信の失敗があると、終了コードが 1 になります。
- スクリーンショットは `e2e-output/<スクリプト名>/` に書き出します（git には入れません）。
- ブラウザの場所が違うときは、環境変数 `E2E_BROWSER` に実行ファイルの場所を入れます。

## 書き方

- 共通の部分は `browser.mjs` の `openBrowser()` にあります（ボタンを文字で押す `click`、選択肢を押す `clickChoice`、キーボードで打つ `typeKeys`、`check`、`layoutCheck`（横スクロールなし・ボタン44px以上）、スクリーンショットなど）。
- 設定は `FAST_SETTINGS`（文字送りなし）で始めます。文字送りそのものを確かめるときは、`freshStart({ settings: … })` で `textSpeed` を変えます。
- 教材（会話の数・単語の数・案内文）に合わせて書いている部分があります。教材を変えたら `chapters.mjs` を直します。
- ゲーム内キーボードには複合母音のキー（ㅝ など）がないので、`typeKeys('ㄱㅗㅁㅏㅇㅜㅓㅇㅛ')` のように分けて書きます。
- 選んだ答え方は、次の往復・次の会話にも引き継がれます（計画 Q9）。選ぶときは `chooseMode('選んで答える')` で戻してから押します。
- 答え方が3つ（選ぶ・書く・話す）のときはタブの文字が短くなるので、タブは `chooseMode`（aria-label で探す）で押します。マイクは `.mic__button` で押します（タブの「話す」と同じ文字のため）。
- ヘッドレスの Edge には音声認識の機能があるので「話す」のタブが出ます。ただし実際に声を聞き取ることはできません。初回の説明と「使わない」までは本物で、聞き取りの流れは偽の音声認識（`phase2.mjs` の `FakeRecognition`）で確かめます。
- ブラウザは「操作の前には音を出させない」設定（`--autoplay-policy=user-gesture-required`）で起動します。効果音の確認は、`Input.dispatchTouchEvent` で指のタップを起こして行います。
- 重ねて出す画面（説明・ログ・紹介）は `main` の外（`#overlay-root`）にあるので、`mainText()` では読めません。`.overlay` から読みます。韓国語の読み上げの音声はないことが多く、その場合は「音声なし」の側（聞いて選ぶ問題を出さない、リスニングを押せない）を確かめます。
- 練習・復習・ドリルの問題の正解は、`practice-answers.mjs` が教材の JSON から求めます（`phase25.mjs`・`phase26.mjs` で共通）。
- `phase26.mjs` は、`speechSynthesis` を偽物に置き換えます（韓国語の音声があることにし、読み上げた文と速さを `window.__spokenLog` に残す）。実際の音は確かめられないので、実機で確かめます。
- `phase25.mjs` は、ページの「今」を `localStorage` の `e2e:dayOffset`（日数）だけ進める小さなスクリプトを入れて、日付を進めます。問題の正解は教材の JSON から求めます（穴埋めは例文と日本語訳の組で探します）。
- 続けて何度も流すと、前のブラウザがプロフィールのフォルダを放す前に次が始まり、`EPERM` で止まることがあります。数秒空けて流し直します。
- `phase2.mjs` は小テストの正解を `src/data/hangul/` と単語の教材から求めます。教材が変わってもそのまま動くはずですが、レッスンの種類や画面の文言を変えたら直します。
- Phase 3 から、はじめからで第1章のおはなしが自動で始まります。自宅から始めたい確認では、`browser.mjs` の `saveAtHome()`（第1章のはじめを終えたセーブデータ）を入れて「つづきから」にするか、`continueToHome()`（つづきから → 始まったおはなしをやめる）を使います。おはなし・案内文・単語カードを進めるには `advanceEvent(条件, 名前)` を使います。
